# Hafta 7 — Tema Uyumlu Günlük Plan

Tema uyumlu bir “Günlük Planım” ekranı. Uygulama cihazın açık/koyu temasını takip
eder ve renklerini buna göre günceller.

## Kullanılan özel bileşenler

- `ThemedView`: Sayfanın tema uyumlu arka planı
- `ThemedLogo`: Tema uyumlu uygulama logosu
- `ThemedText`: Başlık ve metin renkleri
- `ThemedCard`: Öncelik ve görev kartları
- `Spacer`: Bileşenler arasındaki düzenli boşluklar

## Özellikler

- Dört günlük görev kartı ve “Bugünün Önceliği” kartı
- Göreve dokunarak tamamlandı/tamamlanmadı durumunu değiştirme
- Tamamlanan görev sayacı
- Açık ve koyu tema göstergesi

## Çalıştırma

```bash
npm install
npm start
```

## Teslim

Uygulamanın ekran görüntüsü `screenshots/` klasöründe tutulur. Projeyi GitHub'a
yükledikten sonra bu klasördeki görseli formdaki dosya alanına ekleyin.
